# Changelog

## v1.0 — 2026-10-21

First public release for Anbernic RG DS Plus, Stock Linux OS.

- Standalone ARM64 binary and one self-contained SonicMania_PLUS launcher.
- D-pad and left analogue defaults for the confirmed Stock controller.
- Deadline-based pacing and non-VSync presentation; near-60 FPS measured in the tested UFO chase.
- Stable 3D face sorting and floor drawing optimisations without changing internal resolution.
- Physical volume keys and quadratic gain curve; restore the pre-game system volume on exit.
- Lower-backlight shutdown and restoration, with launcher cleanup and an independent watcher.
- 44.1 kHz stereo audio, audio/frame diagnostics and SELECT+START exit.
- PNG menu icon by hatemtiger, with attribution and original source link.
- Complete modified source snapshot, third-party licence notices and build notes.

Private test builds preceding v1.0 are documented only as development history in `Sources/history`.
