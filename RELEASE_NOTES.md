# Sonic Mania Plus for RG DS Plus — v1.0

First public standalone release for **Anbernic RG DS Plus running Stock Linux OS**.

- One SonicMania_PLUS launcher, native ARM64; no RetroArch core or PortMaster required.
- D-pad and left analogue stick ready to use.
- Near-60 FPS in the tested Special Stage 1 UFO chase (59.93–60.07 FPS in steady report windows).
- Physical volume controls with quadratic gain; restore the console's pre-game volume on exit.
- Lower backlight off during play, with previous brightness restored on exit.
- Stereo audio, normal SELECT+START exit, diagnostics and source/build notes.
- Included icon by **hatemtiger**: [original artwork](https://www.deviantart.com/hatemtiger/art/Sonic-Mania-Plus-icon-ico-945862352).

## Install

Download **SonicManiaPlus_RGDSPlus_v1.0.zip** from Assets, extract it, and merge its APPS
folder into the APPS location used by your Stock menu (normally TF2/Roms/APPS).
Place your own Data.rsdk at APPS/SonicMania_RGDSPlus/Data.rsdk and launch SonicMania_PLUS.

Keep your existing saves, options and controller mapping. The old base launcher is archived
on first run; only one main menu entry is used. The included Imgs folder provides the Plus icon.

**Game data is not included. You need your own legally obtained game data and appropriate
game/DLC licence.** The executable defaults to DLC off; selecting the Plus launcher explicitly opts in.

Performance measurements cover the tested gameplay, not every possible scene. Occasional
long frames and loading pauses remain. This is an unofficial, noncommercial port.
See the README, CREDITS and licence notices for upstream authors and conditions.

Assets: installable ZIP, SHA256SUMS.txt, and the complete source archive.
